# AI Media - 自媒体内容创作 SOP 系统

> 热点追踪 → 选题策划 → AI写作 → 人机协作 → 微信公众号一键发布

一个完整的自媒体内容创作工作流，让 AI 成为你的写作助手，而不是替代你。

---

## 核心理念

> **AI 是助手，不是替代者**

我们相信：
- AI 应该帮助人类**更高效地创作**，而不是**替代人类思考**
- 最好的内容来自**人机协作**，不是纯 AI 生成
- 每个作者都有**独特的风格**，AI 应该适应作者，而不是让作者适应 AI

---

## 核心特性

### 1. 热点追踪 - 21个数据源

整合全球优质科技媒体，让你不错过任何一个热点：

**英文数据源**
| 来源 | 特点 |
|------|------|
| Hacker News | 技术圈风向标 |
| Reddit Tech / AI | 社区热点讨论 |
| BBC Tech | 国际科技新闻 |
| The Verge | 科技产品深度 |
| Ars Technica | 科技深度长文 |
| MIT Tech Review | AI 前沿科技 |
| Wired | 科技文化 |
| VentureBeat AI | AI 行业分析 |
| TechCrunch | 创业投资 |

**中文数据源**
| 来源 | 特点 |
|------|------|
| 36氪 / 虎嗅 / 钛媒体 | 科技商业媒体 |
| 机器之心 / 量子位 | AI 人工智能 |
| 极客公园 / 爱范儿 / 品玩 | 科技数码 |
| 澎湃新闻 / 雷锋网 | 综合科技 |

### 2. AI 选题 - 爆款角度生成

从热点自动生成 2-5 个爆款选题角度：

| 风格 | 描述 |
|------|------|
| 怼人流 🔥 | 敢说敢怼，引发讨论，专治各种不服 |
| 内幕流 🔍 | 揭秘行业真相，"其实 XX 是这样的" |
| 反常识流 🤯 | 颠覆认知，"你们都错了" |
| 故事流 📖 | 用案例讲故事，看完当爽文 |

### 3. 逐段写作 - 人机协作

**不是 AI 写完你改，而是每一段都协作：**

```
选题 → 生成大纲 → 开始写作
  ↓
AI写第1段 → 你修改 → 确认
  ↓
AI写第2段 → 你修改 → 确认
  ↓
...
  ↓
所有段落完成 → 汇总成稿
```

**每一步都可以修改：**
- 修改文章标题
- 修改章节标题（添加/删除章节）
- 添加/删除/修改观点（每章 2-3 个观点）
- 修改 AI 生成的任何内容
- 不满意？一键重新生成

### 4. 用户偏好学习 - 越写越懂你

**记录你的每一次修改，分析你的写作风格：**

```
你修改内容 → AI记录 → 分析模式 → 应用到下次生成
```

**学习的内容：**
- 标题风格偏好（争议性/疑问句/数字列表/震惊体）
- 章节数量偏好（几章、几个观点）
- 语气倾向（犀利/温和/以理服人）
- 内容深度（详尽深入/简洁一针见血）
- 结尾风格（留彩蛋引发讨论/直接给结论）
- 常用词汇和表达方式

**学习进度：**
| 阶段 | 条件 | 说明 |
|------|------|------|
| 初次使用 | 0篇文章 | 标准生成，无个性化 |
| 学习中 | 1篇文章或3次修改 | AI开始适应你的风格 |
| 已适配 | 3篇文章或10次修改 | 风格基本稳定 |
| 已掌握 | 5篇文章或20次修改 | 完全按你的思路写 |

### 5. 写作铁律 - 刻进 DNA

```
1. 禁止反问句！！！读者不是来回答问题的，是来看答案的
2. 层层递进，像剥洋葱，让读者欲罢不能
3. 每句话都有信息量，不废话，不重复前文
4. 开头直接抛出观点，让读者快速知道讲什么
5. 像看小说一样，一层层往里面扒
```

### 6. 微信公众号格式

**一键复制，带完整 HTML 排版：**

```bash
使用方法：
1. 点击"复制微信格式"
2. 打开微信公众号后台
3. 编辑器右上角 ··· → 源码
4. 粘贴 → 切换回富文本模式
```

格式包含：居中标题、首行缩进、段落间距、分割线、结尾标识

## 完整 SOP 流程

```
┌─────────────────────────────────────────────────────────────┐
│  1. 热点追踪                                              │
│     → 勾选感兴趣的热点                                    │
│     → 点击"生成X个爆款选题"                              │
├─────────────────────────────────────────────────────────────┤
│  2. 选择选题                                              │
│     → AI 生成 2-5 个角度供选择                           │
│     → 点击"去写作"自动跳转到写作页面                      │
├─────────────────────────────────────────────────────────────┤
│  3. 确认选题 & 生成大纲                                  │
│     → 选题自动继承，支持修改                              │
│     → 每章 2-3 个观点，可编辑                            │
│     → 添加/删除章节，添加/删除观点                         │
├─────────────────────────────────────────────────────────────┤
│  4. 逐段写作                                              │
│     → AI 写一段，你修改一段                               │
│     → 不满意就"重新生成"                                │
│     → 满意就"确认并下一段"                              │
│     → 循环直到所有章节完成                                │
├─────────────────────────────────────────────────────────────┤
│  5. 成稿 & 发布                                          │
│     → 一键复制微信格式，直接粘贴发布                      │
│     → 保存到草稿箱备份                                    │
│     → 添加到发布排期                                      │
└─────────────────────────────────────────────────────────────┘
```

## 技术栈

- **框架**: Next.js 16 + React
- **语言**: TypeScript
- **样式**: Tailwind CSS + shadcn/ui
- **状态管理**: Zustand + localStorage persist
- **AI**: DeepSeek API
- **数据源**: RSS + Hacker News API + Reddit API

---

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/JoesFyj/ai-media.git
cd ai-media

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local，填入 DeepSeek API Key
NEXT_PUBLIC_DEEPSEEK_API_KEY=your_api_key_here

# 4. 启动开发服务器
npm run dev

# 5. 打开 http://localhost:3000
```

## 梦想与目标

### 核心理念

> **AI 是助手，不是替代者**

我们相信：
- AI 应该帮助人类**更高效地创作**，而不是**替代人类思考**
- 最好的内容来自**人机协作**，不是纯 AI 生成
- 每个作者都有**独特的风格**，AI 应该适应作者，而不是让作者适应 AI

### 创作使命

让每一个有想法的人，都能高效地把自己的观点传递给世界。

### 长期愿景

| 阶段 | 目标 | 说明 |
|------|------|------|
| V1 | 人机协作写作 | ✅ 当前版本，已实现 |
| V2 | 多平台适配 | 一篇文章，智能改写适配公众号/知乎/小红书 |
| V3 | 数据闭环 | 追踪文章阅读量、评论、转发，用数据指导创作 |
| V4 | 团队协作 | 支持多人协作、审稿、发布管理 |
| V5 | 知识库 | 积累历史文章，形成个人知识体系 |

### 价值观

1. **效率优先** - 用技术减少重复劳动，让创作者专注思考
2. **个性尊重** - 每个作者都是独特的，AI 应该适应你
3. **质量为本** - 层层递进、观点鲜明、不废话
4. **用户主导** - AI 建议，你来决定
